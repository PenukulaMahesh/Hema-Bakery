HEMA BAKERY WEBSITE
===================

Files
- index.html: website structure and content
- css/style.css: responsive styling
- js/script.js: mobile navigation, cake category filters, and footer year
- assets/: original SVG illustrations used by the site

How to run
1. Extract the ZIP file.
2. Open index.html in a browser.
3. For development, open the folder in VS Code and use the Live Server extension.

Customisation notes
- The phone number is set to 7989839636.
- The address and Instagram profile are based on the details supplied.
- Replace the SVG illustrations in assets/ with real bakery/cake photos whenever available.
- Update the Instagram URL if the official account URL differs.
- The site uses Google Fonts; an internet connection is needed to load them. System fallbacks are included.
